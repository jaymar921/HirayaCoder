HirayaCoder
v1.0.0
for Visual Studio Code  ·  powered by Ollama

An agent that does the work — and shows you every step.

Not autocomplete. HirayaCoder plans, reads, edits, and runs your project across many files, then reports what actually happened — checked against what changed on disk, never against its own account of itself.

Nothing leaves your machine

Loopback-only by design — a non-local Ollama endpoint is rejected outright. No telemetry, no account, no cloud fallback.

You approve every change

Writes and deletes arrive as one reviewable diff. Commands run only from an allow-list you control, confined to your workspace.

Agentic on every model

The agent tracks what it has already read, written and run — so even a 1B model stops going in circles and gets to the writing.

Big requests become a checklist

Your headings, numbered steps and folder tree are the checklist — read from your own request, no extra model call, one step at a time.

Knows your machine

OS, toolchain, and shell rules are detected and stated up front — so the agent never guesses mkdir -p vs md.

It learns your project

Session memory, an audit log, and per-model adaptation — a model that trips the same guard twice gets the correction, locally.
